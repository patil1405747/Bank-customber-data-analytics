# Bank Customer Data Analytics Dashboard

This project is a data analysis dashboard created to examine bank customer segmentation, transaction behavior, and account trends.

## 🛠️ Tech Stack Used
* **Tool:** Power BI (`bank customer analytics.pbix`)
* **Database/Queries:** SQL (`bankdb.sql`)
* **Visuals:** Dashboard Preview (`bank customer data analytics pr...`)

## 📊 Project Overview
* Analyzes customer demographics, account balances, and activity metrics.
* Helps banking institutions understand customer churn patterns and improve targeted financial services.
